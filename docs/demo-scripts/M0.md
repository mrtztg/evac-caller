# M0 demo script: a real phone call

## One-time setup (human)
1. Copy `.env.example` to `.env`. Fill in `SLNG_API_KEY` and `TEST_PHONE_NUMBER` (E.164 format, for example `+34600000000`).
2. Vonage: get a phone number and a SIP trunk. If the account is a **trial**, add `TEST_PHONE_NUMBER` as a test number. A trial can only call allowed numbers.
3. SLNG dashboard: *Telephony → Outbound → Add connection → Manual*, with the Vonage SIP host and credentials. Wait until the status is **active**.
4. Run `pnpm agent:sync`. It creates or updates the SLNG agent, attaches the active outbound connection and prints the line number. If it prints `SLNG_AGENT_ID=...`, add that line to `.env`.

## Steps
1. `pnpm check` passes: run `scripts/check.sh`. Expect `check: OK`.
2. `pnpm agent:sync`. Expect `Updated agent <id> (evac-call-vN)` with N = `PROMPT_VERSION` in `apps/agent/src/slng/evac-agent.ts` and `Outbound line: evac-caller +447451265034`.
3. `pnpm call:test`. Expect JSON with `"mode": "LIVE"`, a `call_id` and `latency_ms`.
4. **NEEDS HUMAN:** the test phone rings within about 15 seconds. The agent says it is an automated call for "Test Care Home" and says it is a test.
5. **NEEDS HUMAN:** ask "Which road should we take?" The agent must say it doesn't have that information and tell you to call 112. It must not invent a road.
6. Save the `call_id` in `docs/PROGRESS.md` as evidence.
